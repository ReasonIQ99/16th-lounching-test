# ReasonIQ99 Website Package

## Included
- `index.html` — Home, Courses, Notifications, About Us and Contact sections
- `styles.css` — Responsive styling for desktop, tablet and mobile
- `app.js` — Course cards, notification details and demo content tools
- `assets/reasoniq99-logo.png` — Provided ReasonIQ99 logo
- `assets/founder-photo.jpg` — Provided founder photo

## Preview locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. No build tools are required.

## Demo admin tools
1. Open the Notifications section.
2. Click **Open Admin Tools**.
3. Demo passcode: `IQ99ADMIN`.
4. Add notifications or attach course files.

Important: This is a static front-end demo. Added notifications and attached files are stored only in the current browser's local storage. They are not uploaded to a server and will not automatically appear for visitors on other devices. For a public production site, connect a secure backend/database and server/cloud file storage, and replace the demo passcode with proper authentication. Do not use the demo passcode on a live site.

## Deploy
Upload the extracted files and folders to your web host's public web directory. Keep the `assets` folder alongside `index.html`.

## Before publishing
- Confirm all official contact and social links.
- Add your official WhatsApp channel URL in `app.js` or `index.html`.
- Add real notification details and verify all official links.
- Configure HTTPS and server-side admin authentication for public uploads.
